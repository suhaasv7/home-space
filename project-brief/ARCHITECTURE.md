## Observed architecture and approved change boundary

Verified stack: Next.js 16, React, TypeScript, Three.js, React Three Fiber and Drei; npm scripts provide dev, build, start, typecheck and test. Retain the stack and hosting.

The measured model uses metre coordinates converted exactly from feet/inches, one shared layout calculation for floor regions/walls/fixtures, and explicit optional furniture sizes. Version-3 home plans save under home-space-home-v3. The prior home-space-home-v2 key remains untouched and can be exported as a backup; incompatible version-2 JSON is rejected with an explicit recovery message. No database or auth changes are part of this request. Fixed-fixture collision detection and survey accuracy for missing dimensions remain out of scope. Broader architecture interview remains pending.
